# Old Well Mowing

Schedule, crew, and photo tracking for Old Well's mowing operation. Auto-syncs every 15 minutes from SharePoint.

🔗 **Dashboard (read-only overview):** https://emw-oldwell.github.io/oldwell-mowing-dashboard/
📱 **Crew + Office app:** https://emw-oldwell.github.io/oldwell-mowing-dashboard/app/ — install to phone via "Add to Home Screen"

## Two surfaces

- **Dashboard (`index.html`)** — wall-mounted / desktop overview. KPIs, past-due, calendar, properties, photo wall. Read-only.
- **App (`app/index.html`)** — mobile-first. Crew signs in to see their day, mark on-way / start / finish, attach photos, leave notes. Office signs in to see live status across all crews, reschedule/reassign, manage properties.

## Crew → Office update flow

The app saves edits on each device. Tapping **Notify office** (or finishing a job) opens the phone's mail app with a prefilled summary addressed to `mow@oldwellco.com` — the shared inbox the office already monitors. Multi-device write-back to SharePoint is the next milestone (see *Roadmap* below).

## Architecture

```
                 ┌──────────────────────────────────────────────┐
                 │              SharePoint Mowing                │
                 │   Schedule list — single source of truth      │
                 │   updated by Photo Intake flow on email       │
                 └──────────────────────────────────────────────┘
                                       │
                          Microsoft Graph (app-only)
                                       ▼
                 ┌──────────────────────────────────────────────┐
                 │   GitHub Actions — .github/workflows/sync.yml │
                 │   runs every 15 min, scripts/sync.py          │
                 └──────────────────────────────────────────────┘
                                       │
                            commits data.json
                                       ▼
                 ┌──────────────────────────────────────────────┐
                 │   GitHub Pages — index.html + data.json       │
                 │   browser auto-reloads every 5 min            │
                 └──────────────────────────────────────────────┘
```

## Files

- `index.html` — the dashboard. Pure static HTML/CSS/JS.
- `data.json` — schedule snapshot. **Do not edit manually** — regenerated by sync.
- `photos/` — photo attachments referenced by `data.json`. Filename pattern: `{JobID}_{originalname}.jpeg`.
- `scripts/sync.py` — pulls schedule from SharePoint, writes data.json.
- `.github/workflows/sync.yml` — runs the sync every 15 min.

## Photos

Schedule sync (data.json) is fully automated. **Photos are still manually pushed** in v1 because:

- SharePoint list attachments aren't exposed in Microsoft Graph
- Direct SharePoint REST app-only access is blocked by tenant policy
- The Power Automate workaround needs a Premium license

**When a new photo lands from a contractor email:**

1. The existing Photo Intake flow saves it to OneDrive (`Oldwell/Mowing_Maint/Photos/`) and attaches it to the matching Schedule row.
2. To make it show on the dashboard, push it to `photos/` here:
   ```bash
   cd /path/to/this/repo
   cp ~/.../Photos/IMG_xxx.jpeg ./photos/J-NNNN_IMG_xxx.jpeg
   git add photos/ && git commit -m "Add photo for J-NNNN" && git push
   ```
3. Next sync run (within 15 min) updates `data.json` with the new attachment URL.

**Naming convention:** `{JobID}_{anything}.jpeg`. The JobID prefix is what links the photo to the right Schedule row in the dashboard.

## Manual sync

To force a sync without waiting 15 min:
- Go to https://github.com/emw-oldwell/oldwell-mowing-dashboard/actions
- Click "Sync schedule from SharePoint"
- "Run workflow" button on the right

## Secrets

The workflow uses these GitHub repo secrets:
- `AZURE_TENANT_ID`
- `AZURE_CLIENT_ID` (an Azure AD app named "OldWell Mowing Dashboard Sync")
- `AZURE_CLIENT_SECRET`
- `SHAREPOINT_HOST` = `oldwellco.sharepoint.com`
- `SHAREPOINT_SITE_PATH` = `/sites/Mowing`

The Azure AD app has `Sites.Read.All` (Application) on Microsoft Graph.
